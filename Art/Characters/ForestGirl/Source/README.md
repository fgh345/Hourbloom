# Forest Girl — 第三版 · 服装细节与步态

按照提供的正面、侧面、背面参考图，用真实几何体制作的低多边形角色。预览是 Blender 对模型的实际渲染，没有用生成图片代替模型效果。

- 重建裙摆褶皱和双道缝边，三叶草与小叶花纹贴合实际布面。
- 添加外套翻折领边、下摆缝线、后背接缝和衬袖翻边。
- 增加包袋滚边与侧袋，轻微倾斜挂包；完善靴子鞋面、鞋眼、鞋带结和提环。

- Walk 改为预计算的两段腿部运动：支撑阶段脚底保持水平，摆腿阶段抬脚，身体有轻微重心起伏，并配合摆臂。
- 修正斜向手臂骨骼的摆动轴；右手适当向外避让包袋，并检查了完整周期的空间间隔。
- 重新导入交付 GLB，对完整周期 25 帧的左右鞋底进行高度检查。数据保存在 `walk_contact_check.json` 和 `hand_clearance_check.json`。

## 使用

Godot：将 GLB 放入项目资源目录，等待导入后拖入 3D 场景。模型里提供 Idle 和 Walk 两段骨骼动画。Walk 是原地步态，不会推动游戏角色的位置；游戏移动仍需要角色控制逻辑。匹配这个 1 秒步态周期的参考前进速度约为每秒 0.759 个源模型单位；整体缩放时速度也需同比例缩放，以减少滑步。本轮没有在 Godot 内运行验证。

Blender：打开 `.blend` 即可编辑。静态展示时两条 NLA 轨道默认静音。可在动画工作区选中骨架，选择 Walk 或 Idle 动作进行预览，避免同时播放两个动作。工程帧率为 24 FPS；Walk 为 1–25 帧，Idle 为 1–49 帧。

模型采用 Z 向上的 Blender 坐标创作，GLB 导出时转换为 Y 向上。源模型高度约 3.7 个单位；游戏中可按角色实际身高统一缩放。

## 当前质量边界

这是可编辑、可导入、带基础动画的第三版原型，不是对参考图的精确复刻。脸部和头发已重做，但布料折叠、发束自然感及整体神态仍未完全达到原图。花纹和五官使用几何色块，腮红直接采用面部顶点颜色渐变；尚未做正式的贴图绘制与材质合批。

Walk 已烘焙脚底接触与屈膝动作，但未提供游戏运行时的地形 IK、根运动、衣服与头发物理、碰撞体、表情动画或游戏控制器。脚底高度检查以水平地面为准，不代表斜坡、台阶或游戏中的实际移动已经验证。部件数量较多，尚未做面向大量角色的渲染优化。
