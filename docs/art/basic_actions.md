# 角色基础交互动作

当前运行角色除既有移动、跳跃和挥锄外，新增 `Seed`、`Harvest`、`Pickup`、`Drop`、`Interact` 五段短动画。动画烘焙在 `Assets/Tools/Hoe/forest_girl_tools.glb`，仍使用相同骨架、贴图和手部网格；锄头仅在挥锄时出现。

`PlayerBasicActionController` 统一驱动动作时间、暂停移动和一次性接触事件。播种、收获、拾取、丢弃及一般交互都在动作接触帧才执行游戏逻辑。目标离开准星、距离过远、地块状态变化、角色失去地面或输入被阻断时，待执行的效果取消。动作过程中不能切工具、再交互或使用另一个工具；结束后恢复原有的走跑跳。

播种和收获在角色正前方约 0.75 米处向下探测地面；播种要求该位置的土壤已经翻耕，且种子的实体占位没有重叠。收获取接触点附近最近的成熟植株。两种动作在接触帧重新验证目标。拾取和一般交互仍使用准星并限制在 2.5 米内。`G` 仍是测试用丢弃键，但会播放丢弃动作再将第一个背包物品放到场景。

动画由 `Art/Tools/Hoe/add_basic_actions.py` 从现有运行 GLB 的空手姿势生成。该脚本重复运行结果相同；重新执行 `build_hoe_runtime.py` 时也会自动在导出后补上这五段。动画目前采用骨骼姿态构建，没有额外的种子、镰刀或手持物网格；正式道具表现可随后加入。`Pickup` 和 `Drop` 使用相似的俯身姿势，接触点和收势不同于农作动作。

验证：Godot 4.7 导入后运行 `Scripts/tests/verify_player_basic_actions.gd`，检查五段导入、接触前不生效、恰好执行一次、取消后不执行，以及真实播种和收获状态变化。原有 `verify_player_hoe.gd` 与 `verify_player_jump.gd` 也需要通过。
