# 开发者工具

按 Esc 打开暂停菜单，点击「设置」，在「开发者工具」中调节「时间流速」。

界面单位是「现实 1 秒＝游戏 N 分钟」，可输入 0.1～60，或选择 1、10、30、60 分钟预设。输入后按 Enter 或移开输入框完成修改。修改立即应用；退出暂停菜单后按新流速继续运行。菜单中显示一个游戏日对应的现实时间。

设置自动保存到本机 `user://developer_settings.cfg`，与游戏存档槽位分开。重启、新开游戏、读取游戏存档都会沿用上次流速。文件缺失、损坏或值无效时使用默认值 1。恢复默认按钮也保存设置；如果保存失败，界面明确提示仍需在下次启动时重新设置。

时间加速影响昼夜、植物生长及按游戏分钟执行的生存状态等系统；不改变角色移动速度或动画速度。暂停菜单保持游戏暂停。

默认一个游戏日为现实 24 分钟。60 分钟预设下，一个游戏日为现实 24 秒，向日葵 72 秒成熟；西瓜分别在 102、108、114、120 秒成熟。

TimeManager 保留不足一分钟的累积时间，并处理每帧所有已累积的游戏分钟，避免高流速或低帧率时漏计时间。分钟信号在时钟进位完成后发出，防止显示 06:60 等未归一化时间。

验证命令：

```sh
godot --headless --path . res://Scripts/tests/verify_developer_time.tscn
```

测试覆盖配置保存恢复、无效值处理、高速计时、跨午夜、不同帧长度、植物实际成熟时间、菜单预设和自定义输入、暂停返回及恢复默认。

另外可使用独立临时用户数据目录执行 `-- startup-write` 与 `-- startup-read` 两次启动，验证完整进程重启后的自动恢复；这两种模式会写入该目录的真实开发者设置，请勿用于正常游玩的用户数据目录。

本次以 Godot 4.6 stable 进行测试及菜单实际渲染；项目目标版本保持 4.7。仓库原有未包含的 godot_mcp_toolkit Autoload 在干净检出时仍会报告缺失。
