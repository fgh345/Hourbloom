# 向日葵与西瓜

## 操作

- `1`：锄头；先翻耕播种点。
- `2`：向日葵种子。
- `3`：采收；靠近成熟植株或瓜，朝向目标后使用左键。
- `4`：西瓜种子。

播种使用角色前方的实际地面坐标，不吸附到一米地块中心。目前种子仍是无限使用的工具，没有增加种子购买、库存或消耗系统。

## 生长与占地

向日葵用约三个游戏日长成：覆土、子叶、茎叶、花苞、双圈黄花瓣和花盘。成熟时收获向日葵籽，移除整株。

西瓜用约五个游戏日生长。根部不移动，每株四条主藤和八条侧藤逐段伸展，沿途出现裂叶、黄花和条纹果实。形态由保存在 CropData 的 shape_seed 决定；相邻植株形状不同，同一植株读档后保持形状。藤蔓半径上限 4.8 米，覆盖范围依据实际已长出的藤蔓计算，可跨越多个地块及区块。

播种时仅检查根部间距：向日葵根部半径 0.12 米，西瓜 0.45 米；成年枝叶允许交错。藤蔓不会因为邻株靠近而整体缩回单格。

一株西瓜有四个果实，分别在生长进度 85%、90%、95%、100% 成熟。按瓜所在位置采摘，每次一个；摘瓜保留藤蔓，所有瓜摘完后不会自动无限再生。harvested_fruits 随作物实例存档保存。旧 generic 作物保留原生长时间，外观按向日葵显示。

## 渲染

CropVisualBuilder 生成低多边形网格，无外部贴图或模型依赖。叶片、藤蔓、花和果实按材质合并网格；远于 24 米时使用简化叶片及果实几何。CropNode 缓存生长进度及采摘状态，成熟后不重复重建网格。

西瓜藤节点采样地面高度；没有有效地面碰撞时回退到根部高度。GridManager 增加根部区块缓冲，避免边界外根部对应的藤蔓突然消失。

当前实现是有形态变化的生长近似，不包括水分、营养、授粉、拥挤减产、绕开障碍或地块边界的生长决策。地形修改后已缓存的藤蔓高度需要重新加载该作物节点。
